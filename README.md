# Foundit

Describe a problem in your own words, get the tools that solve it.

Foundit is a desktop-web app. Instead of searching for a tool by name, you say what
you are trying to do — *"a free way to split expenses with friends while travelling"* —
and it recommends real apps, websites and small software projects, each with a score
showing how well it fits what you actually asked for.

## Where things are

| Folder | What lives there |
| --- | --- |
| `docs/` | The product spec, the design research, and the decisions we have made |
| `design/canvas/` | The full UI design — 37 screens, generated by `build.mjs` |
| `research/` | Engineering research: cost, matching, security, schema, devops, performance |
| `supabase/` | Database schema and migrations (added in the build phase) |
| `app/` | The application itself (added in the build phase) |

## The two environments

| | Production | Development |
| --- | --- | --- |
| Branch | `main` | `develop` |
| Who sees it | The public | Only you |
| Database | The production Supabase project | A separate development Supabase project |
| Deploys when | You merge `develop` into `main` | You push to `develop` |

Nothing is ever changed directly in production. Work happens on `develop`, gets checked,
and is then merged into `main`. Both the app and the database follow that same path.

## Ground rules for this project

1. **Nothing costs money without a hard cap.** Every service that can bill us has a
   spending limit set, and the app enforces its own limits on top of that.
2. **Strangers can read; only signed-in people can write.** Enforced in the database
   itself, not just in the app code.
3. **Reviews belong to whoever wrote them.** Nobody — not the tool's owner, not us —
   can edit or delete someone's review.
4. **Whoever adds a tool maintains it.** Only listings seeded at launch can be claimed.
5. **Schema changes travel as migration files**, never as clicks in a dashboard.

## Working on it

```bash
npm install
npm run dev
```

The design canvas can be regenerated at any time:

```bash
node design/canvas/build.mjs
```
